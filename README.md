# JDBC
Employee Records to CSV Exporter
A Java application that retrieves employee records from an Oracle database using JDBC and exports them to a CSV file.

Features
Connects to an Oracle database using JDBC.
Retrieves employee details using an SQL query.
Reads query results using ResultSet.
Writes employee records to a CSV file.
Handles database connection, SQL, and file-writing errors.
Technologies Used
Java
JDBC
Oracle Database
Oracle JDBC Driver
CSV file format
Prerequisites
Java Development Kit (JDK)
Oracle Database with an employee table
Oracle JDBC driver compatible with your JDK
VS Code or another Java IDE
